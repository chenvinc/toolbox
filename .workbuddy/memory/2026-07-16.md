# 2026-07-16 工作日志

## 行间距与阈值控件统一整改（UI 仅渲染层）
- 新增通用组件 `widgets.StepperInput`：左侧− / 中间输入 / 右侧+ 步进控件，彻底隐藏原生上下箭头（up/down-button/arrow 宽度高度归零+image:none）；中间支持 QDoubleSpinBox/QSpinBox(透传 value) 与 QLineEdit(± 按 step clamp 到 [min,max]，value() 解析 float 回退 default)。样式全用全局令牌，无自定义参数。
- slide_view：行间距模块新增小标题「行间距设置」(复用 qss_section_header 13px bold + card_header_color，加入 _section_labels)；单行 [下拉1倍/1.5倍/自定义][自定义行距 stepper 仅自定义时显示][首行缩进]，删除“自定义行距”静态标签；自定义行距由 QDoubleSpinBox 改为 QLineEdit(占位“请输入行距倍数”+QDoubleValidator 0.5–5.0 step0.1 default2.0)，取值改 `line_spacing_value_stepper.value()`；字号(QSpinBox)与自定义行距均包 StepperInput。注意：LineSpacingType 枚举值为 "1 倍"/"1.5 倍"/"自定义"（带空格），下拉项字符串不得改，否则后端解析失败。
- similarity_view：相似度阈值改为 StepperInput(spin=self._threshold_spin)，保留 _threshold_spin 为 QDoubleSpinBox（测试 view._threshold_spin 依赖），移除原 _thr_minus/_thr_plus 与 step_s；input_s 仅保留 QLineEdit 规则。
- 易错点：QDoubleValidator 在 PySide6 中属于 PySide6.QtGui，不是 QtWidgets（slide_view 初版误导入 QtWidgets 已修正）。
- 验证：py_compile 三文件 OK；unittest discover 38/39（仅历史损坏 QtTaskRunner 仍遗留，无关）；组件+视图 offscreen 冒烟全 PASS。报告 docs/行间距与阈值控件统一整改报告.md。
