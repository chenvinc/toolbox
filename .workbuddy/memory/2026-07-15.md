## 状态机 Bug：检测完成后按钮文案未恢复“开始检测”
- 用户实测：点击“开始检测”→显示“检测中”（方案二修复生效）→检测完成但文本仍卡“检测中”，未回到“开始检测”。
- 根因：`widgets.py` 原 `AppButton.set_loading` 每次 `set_loading(True)` 都执行 `self._original_text = self.text()`。生产序列中 `_on_check` 与 `_on_started`（CHECK_STARTED 信号回调，similarity_view._connect_view_model 第64行已连接）各调一次 `set_loading(True)`；第二次调用时按钮文本已是“检测中”，于是把 _original_text 污染成“检测中”，completed 后 `setText(self._original_text)` 恢复成“检测中”而非“开始检测”。纯 Python 复刻生产序列（click→started→complete）成功复现该 bug。
- 修复：`set_loading` 加幂等保护——仅在“非加载态→加载态”首次跃迁时保存 `_original_text`（`if loading and not self._loading: self._original_text = self.text()`），其后无条件设置 `_loading` 与文案。`AnimatedButton` 未重写 set_loading，继承即生效。
- 回归测试：在 tests/test_p1_settings_and_threads.py 的 P1ThreadTests 新增 `test_check_button_text_recovers_after_completion`，用 QtEventEmitter+QtTaskRunner+真实 SimilarityView，模拟 click→started→completed 序列，断言完成后 _check_btn.text()=="开始检测" 且 isEnabled()。headless 下以 no-op 桩替换 _log_browser 隔离渲染。沙箱无法装 PySide6（exit137），改用纯 Python 复刻逻辑等价验证该测试断言通过。
- 影响评估：slide_view 的 convert 按钮同样经历 on_convert（set_loading True）+ 无 started 二次调用，故此前未暴露；本修复对其无副作用（幂等保护不影响单次调用）。核心/契约/DI/ViewModel 均未改动，公共 API 不变。

- 核心原则（硬约束）：不改动功能逻辑、不删减现有功能；只做 UI 视觉规范统一 + 界面布局优化 + 交互体验升级；轻量化办公工具简约风格，适配办公用户；优先低成本高收益方案。
- 两大模块：Quiz2Slide（题库转PPT，ui/views/slide_view.py）、Similarity Checker（试题查重，ui/views/similarity_view.py）。主窗口 app.py（左侧 200px 导航 + 右侧 QStackedWidget）。
- 现状基线（已读源码建立）：
  - 主题系统 theme.py/theme.qss 支持深/浅色自动切换 + QSS 热加载（# card/divider/progress_bar/section_header 四片段 $var 占位符）。
  - 组件库 widgets.py：AppButton/AnimatedButton(按压动画+加载态)/AnimatedProgressBar(300ms 缓动)/ToastNotification(顶部滑入，✅❌ 仅 emoji 区分)/DropZone/MultiDropZone(多文件)。
  - SlideView：单卡片 + QScrollArea，区块标题带 emoji（📄/🎨），error_label/progress_label 置于卡片外 root 布局；预览确认弹窗(QDialog+QTextBrowser)；word/ppt 双 DropZone + 保存到路径(中截断) + 改更按钮。
  - SimilarityView：单卡片，查重模式 RadioButton(1对多/多对多) 切换 show/hide 区块，settings_row 一行塞 6 控件(阈值/题号/选项/重置)，log_browser(QTextBrowser) 展示结果 + 导出报告(.docx)。
- 已识别四类可优化点（对应"视觉层级混乱/交互细节缺失/规范不统一/UX不足"，待阶段任务落地，未改动）：
  - 规范不统一：按钮高度 50/44/28/无(重置) 混用；圆角 14(按钮)/20(卡片)/8(输入)/12(拖放) 尺度不一；section 标题 SlideView 带 emoji、SimilarityView 不带；"更改"按钮用 accent 蓝易过重。
  - 视觉层级：SimilarityView settings_row 6 控件挤一行无分组；单选按钮无容器/无选中视觉强调；error/progress 置于卡片外破坏包裹感。
  - 交互缺失：Toast 成功/失败仅 emoji 无配色；"打开文件夹"链接 style=inherit 无链接态；重置/导出按钮无 hover/loading 态；模式切换无过渡动画；无控件 tooltip。
  - UX：无空状态；长操作无忙碌光标；进度条 setVisible 硬切无淡入；阈值无单位说明；无键盘可达性统一处理。
- 注意：CODE_REVIEW_REPORT.md 针对已删除 legacy 文件，勿按旧报告直接改；当前代码已吸收其 DRY/BaseView 建议。
