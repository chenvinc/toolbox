## 二、第一部分：Quiz2Slide「行间距设置」模块重构

### 1. 模块小标题
- 在行间距控件上方新增小标题 **「行间距设置」**，样式严格复用全局 `section_header`：
  `font-size: 13px` · `font-weight: bold` · `color: card_header_color`（浅色 `#333333` / 深色 `#f5f5f7` 自动适配）。
- 该标题加入 `_section_labels`，随主题切换（`_restyle_all`）自动重渲染。

### 2. 单行横向布局
- 小标题下方为单行 `QHBoxLayout`（`spacing = 8px`）：
  - **左侧下拉框**：选项固定 `1 倍` / `1.5 倍` / `自定义`（字符串与后端 `LineSpacingType` 枚举值严格一致，**未改动**，保证 `_resolve_line_spacing` / `GeneratePptxRequest` 解析逻辑不变）。
  - **右侧行距数值输入框**：默认 `setVisible(False)`，**仅当选中「自定义」时显示**（逻辑 `_on_spacing_changed` 不变）。
- 下拉框与输入框高度均 `36px`，在同行内垂直居中对齐。

### 3. 删除冗余静态标签 + 占位提示
- **彻底删除**原常驻右侧的「自定义行距」静态文字标签（不再使用 `_make_labeled_field("自定义行距", …)`）。
- 输入框占位提示文本设置为 **「请输入行距倍数」**（通过 `QLineEdit` + `QDoubleValidator(0.5, 5.0, 1)` 实现；因 `QDoubleSpinBox` 无占位文本能力，故中间层由 `QDoubleSpinBox` 改为受校验约束的 `QLineEdit`，数值范围/步长/默认值 0.5–5.0 / 0.1 / 2.0 全部保留）。

### 4. 全局规范统一
- 下拉框沿用 `combo_s`（圆角 `radius=6px`、透明边框 hover 变主色、focus 变主色实线 + 卡片底）。
- 输入框/步进控件沿用全局令牌（`input_bg` / `accent` / `card_bg` / `border` / `radius`），深浅模式配色一一对应。

### 5. 业务逻辑保留
- 行距取值仍经 `line_spacing_value_stepper.value()` 返回 `float`，原 `_prompt_and_convert` 中 `_resolve_line_spacing(...)` 与 `GeneratePptxRequest(line_spacing_value=...)` 调用点**仅改取值对象、语义不变**。
- 首行缩进、字号排版、PPT 生成等逻辑均未触碰。

### 6. 全页面数值输入框步进标准化
- **字号（QSpinBox）** 与 **自定义行距（QLineEdit）** 统一包装为 `StepperInput`：左侧减号 + 中间输入框 + 右侧加号，彻底移除原生上下箭头。
- 与查重页「相似度阈值」步进控件 **1:1 外观一致**（同一组件类）。

## 三、第二部分：Similarity Checker 相似度阈值控件清理

### 1. 移除重复调节控件
- 保留输入框左右两侧「−」「+」步进按钮；通过 `StepperInput` 的 `_middle_style()` 将 `QDoubleSpinBox` 的原生 `up-button / down-button / up-arrow / down-arrow` 宽度与高度归零并清除箭头图像，**彻底移除输入框内部原生上下箭头**，消除重复调节问题。

### 2. 全局规范 1:1 对齐
- 步进控件（中间输入 + 两侧按钮）的圆角、尺寸、配色、hover/禁用态全部由 `StepperInput.set_theme(t)` 驱动，与 Quiz2Slide 改造后的同类输入框 **外观完全一致**，实现全软件控件视觉标准化。
- 阈值的取值范围（0.5–1.0）、步长（0.01）、小数位（2）、持久化（`QSettings` → `_save_settings`）等后台参数**完全不动**；`self._threshold_spin` 仍保留为 `QDoubleSpinBox` 实例，既有测试 `view._threshold_spin.value()/setValue()` 接口不受影响。

## 四、新增通用组件 `StepperInput`（`widgets.py`）

统一封装「− 输入框 +」步进控件，中间层支持三种形态：
- `QDoubleSpinBox` / `QSpinBox`：保留其 `range / singleStep / decimals / value`，仅隐藏原生箭头；`value()` 透传内部控件。
- `QLineEdit`：由调用方设置 `QDoubleValidator` 约束；± 按钮按 `step` 增减并 `clamp` 到 `[min, max]`，`value()` 解析文本返回 `float`（空/非法时回退 `default_value`）。

样式全部来自全局主题令牌，不新增任何自定义 CSS 变量。
