# 阶段 2 布局与视觉层级优化报告

> 范围：Quiz2Slide（题库转 PPT）、Similarity Checker（试题查重）两大模块全页面 + 左侧导航
> 目标：重构视觉层级、模块化拆分功能区、优化导航与控件排版，解决拥挤、层级模糊、可读性差
> 日期：2026-07-15
> 前置：阶段 1 全局 UI 规范已统一（色彩 / 圆角 / 间距 / 字体 / 按钮令牌已落地）

---

## 一、优化结论

两大功能页面与左侧导航已完成**视觉层级重构与模块化拆分**：导航加图标与中文释义、强化选中态与 hover 交互；Quiz2Slide 拆为四大浅灰圆角功能卡片；Similarity Checker 的文档区同样卡片化、主/副文档上传框主次级边框区分、参数网格对齐、检测结果由纯文本升级为**结构化卡片（高亮重复率 / 重复题目数）**。页面分区清晰、规整、新手可快速看懂功能流程。全程未改动任何功能逻辑。

---

## 二、优化点对比（原版 → 优化）

### 1. 左侧侧边导航

| 维度 | 原版 | 优化后 |
|------|------|--------|
| 大标题「工具箱」 | 14px 居中，无留白 | **16px 加粗**，下边框分隔 + 底部留白（24/16px） |
| 功能入口 | 纯英文 `Quiz2Slide` / `Similarity Checker` | **图标 + 中文释义**：📑 题库转PPT / 🔍 试题查重（tooltip 保留英文原名+描述） |
| 选中态 | 仅底色变化 | 底色加深 + **左侧 3px 蓝色竖线指示器**，文字加粗 |
| hover 交互 | 纯底色 | **浅蓝渐变高亮**（从左向右 qlineargradient） |
| 条目内边距 | `12px 20px`、贴边 | 统一 `12px 16px` + `margin 4px 10px`，消除文字贴边 |

### 2. Quiz2Slide 题库转 PPT

| 维度 | 原版 | 优化后 |
|------|------|--------|
| 页面结构 | 单层大卡片 + 平铺区块标题 | **四大浅灰圆角模块卡片**：导入源文档 / 幻灯片样式自定义 / 套用 PPT 模板 / 输出路径设置，各带加粗 13px 小标题 |
| 输入框 / 标签 | 单行内联标签，基线不齐 | **标签置顶 + 控件下方**的统一网格（`_make_labeled_field`），输入框统一高 36px、圆角 6px |
| 占位提示 | `1.` / `A.` | **示例引导**：`如 1.` / `如 A.` |
| 首行缩进 | 复选框文案「是」，语义模糊 | **「启用首行缩进」前置复选框**，语义清晰 |
| 上传框 | 虚线边框 + hover（一致） | 保持统一虚线边框 + hover 主色边框（一致性延续） |

### 3. Similarity Checker 试题查重

| 维度 | 原版 | 优化后 |
|------|------|--------|
| 文档上传区 | 无分组，主/副框样式相同 | **模块卡片化**（主文档 / 副文档 / 所有文档），主文档上传框 **主色虚线边框（强调）**、副文档 **中性虚线边框**，主次差异化 |
| 参数行 | 6 控件挤一行（阈值/题号/选项/重置），标签内联易错位 | **网格对齐**：阈值 / 题号格式 / 选项前缀 各自「标签置顶 + 控件」对齐，重置按钮右对齐 |
| 单选 / 标签 / 输入间距 | 紧凑 | 统一 `spacing 8~12`，消除拥挤感 |
| 检测结果展示 | **纯文本**追加到 QTextBrowser | **结构化卡片**：摘要卡大字号高亮「重复率」「重复题目数 / 总题目数」，每条重复题 / 重复对独立子卡（来源文件、相似度、原因） |

## 三、改动清单

| 文件 | 改动要点 |
|------|----------|
| `app.py` | 导航大标题放大加粗（16px）+ 下边框 + 底部留白；导航项改用 `get_nav_title()`（图标+中文），tooltip 含英文原名；选中态加 `border-left: 3px solid` 蓝色指示器；hover 改浅蓝渐变；条目内边距 / margin 统一。**修复启动崩溃**：`_apply_global_font` 误用 `@staticmethod` 却引用 `self`，导致 `ToolboxApp` 实例化即 `NameError`——移除装饰器改为实例方法（此前测试未实例化 `ToolboxApp`，故一直潜伏） |
| `ui/views/base_view.py` | 新增 `get_nav_title()` 默认实现（回退 `get_name()`），供各视图重写中文入口名 |
| `ui/views/slide_view.py` | 拆分为 4 个 `_make_module_card` 模块卡片（标题 + 圆角浅灰卡）；`_make_labeled_field` 统一网格；占位符改为 `如 1.`/`如 A.`；首行缩进复选框文案改「启用首行缩进」；输入框统一高 36px；外层容器透明、模块卡片承载浅灰底，形成层级对比；`_restyle_all` 改为按模块卡片批量套用 `qss_card` |
| `ui/views/similarity_view.py` | 文档区 `_make_module_card` 卡片化；`DropZone`/`MultiDropZone` 传 `variant` 实现主/副边框差异化；参数改为 `_make_labeled_field` 网格对齐 + 重置右对齐；新增 `_render_result` / `_build_one_to_many_cards` / `_build_many_to_many_cards` / `_card` / `_clear_layout` / `_show_result_placeholder`，以结构化卡片替换纯文本结果；保留紧凑处理日志；`_restyle_all` 支持按当前主题重渲染结果卡 |
| `widgets.py` | `DropZone` / `MultiDropZone` 新增 `variant` 参数：`primary` 用主色虚线边框（主文档强调），`secondary` 用中性虚线边框；两者 hover / 拖拽均切换主色实线边框 + 悬浮底色 |

## 四、验证结果

- **语法校验**：`app.py` / `widgets.py` / `base_view.py` / `slide_view.py` / `similarity_view.py` 全部 `py_compile` 通过。
- **启动冒烟（offscreen）**：成功实例化 `ToolboxApp`，双视图构建无异常；导航标题为 `📑 题库转PPT` / `🔍 试题查重`；SlideView 含 4 个模块卡片、SimilarityView 含 3 个模块卡片；首行缩进复选框文案为「启用首行缩进」；主文档上传框 `variant=primary`、副文档 `variant=secondary`。
- **双主题重渲染**：浅 / 深两套 `Theme` 下 `_restyle_all` 与结果卡片 `_render_result` 均无异常，颜色随主题切换正确。
- **结构化结果卡**：1对多 / 多对多两种结果均成功构建摘要卡 + 明细子卡，重复率 / 重复题目数高亮正确。
- **单元测试**：**38 / 39 通过**。唯一错误仍为历史遗留损坏测试 `test_p1_settings_and_threads.test_check_button_text_recovers_after_completion`（`NameError: QtTaskRunner`，早期沙箱无法运行 PySide6 时遗留，与本次 UI 优化无关），未改动。

## 五、原版可改进点回顾（已在本阶段解决）

- 界面拥挤、模块无边界 → 模块卡片化 + 统一间距。
- 层级模糊、区块仅文字标题 → 卡片 + 加粗小标题形成视觉分区。
- 导航纯英文、无图标 → 图标 + 中文释义，降低新手认知门槛。
- 查重结果纯文本、核心数据不突出 → 结构化卡片高亮重复率 / 重复题目数。
- （附）应用启动即崩溃 → 修复 `_apply_global_font` 静态方法误用 `self`。
