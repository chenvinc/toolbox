# 阶段 3：交互细节与体验升级 — 最终版成果报告

> 范围：Quiz2Slide（题库转 PPT）与 Similarity Checker（试题查重）双页面
> 原则：不改动功能逻辑、不删减功能，仅做交互/容错/状态反馈的精细化升级
> 风格：轻量化办公简约风，严格复用「全局 UI 规范（双模式）」设计令牌

---

## 一、文件上传模块交互优化

### 1.1 拖拽悬浮反馈（双页通用）
- `DropZone` / `MultiDropZone` 在 `dragEnterEvent` 时切换为「主色实线边框 + 淡蓝悬浮底」（`_drag_style`），`dragLeaveEvent` 恢复。
- 主文档框（`variant="primary"`）与辅助框（`variant="secondary"`）均保留「中性虚线 → 主色实线」的主次视觉层级。

### 1.2 单文件删除按钮（题库转 PPT 双框 / 查重主文档框）
- `DropZone` 选中文件后，右侧出现圆形「✕」删除按钮（`file_cleared` 信号 → 视图清空对应路径并重置按钮态）。
- 删除按钮 hover 变红（复用 `danger` 令牌），点击空白处仍可继续选文件（`mousePressEvent` 已排除按钮区域）。

### 1.3 多文件列表 + 批量清空（查重副文档 / 所有文档）
- `MultiDropZone` 重构为自管理列表：每个文件一行（省略文件名 + 完整路径 tooltip + 单删「✕」）。
- 列表底部「清空全部」按钮一键清空（`files_selected([])` 广播，视图同步清空路径）。
- 追加选择时不覆盖已有文件、自动去重；单删 / 清空后均实时刷新列表可见性。

### 1.4 长文件名省略 + hover 完整路径
- 文件名经 `QFontMetrics.elidedText(..., ElideMiddle, …)` 省略，鼠标悬浮显示完整路径 `setToolTip`。

### 1.5 格式校验（轻量 Toast 提示）
- 从 `file_filter`（如 `Word 文档 (*.docx)`）解析允许后缀，拖入 / 选择不合规文件时发射 `invalid_file`，视图层弹出 ❌ Toast（`文件格式不支持：xxx`），且不污染已选文件。

## 二、按钮与操作状态逻辑优化

### 2.1 主按钮无文件置灰（不可点击）
- **题库转 PPT**：`_update_convert_state()` 依据 `_word_path` / `_ppt_path` 置灰「开始转换」，并 hover 提示「请先选择 Word 文档 / PPT 模板」。
- **试题查重**：`_update_check_state()` 依据模式与已选文件置灰「开始检测」（1对多需主文档 + ≥1 副文档；多对多需 ≥2 份文档）。
- 文件增删、模式切换、检测完成均实时刷新按钮态；加载中（`_loading`）受幂等保护不被误覆盖。

### 2.2 任务执行 loading + 动态文案（防重复点击）
- 沿用 `AnimatedButton.set_loading()`：「转换中…」/「检测中…」动态文案 + 禁用 + 按压动画；加载期间点击事件被忽略（`mousePressEvent` 拦截），杜绝重复触发。

### 2.3 导出按钮状态区分
- 查重「导出报告」初始 `set_actionable(False, "请先完成检测后导出")`；仅在 `_on_completed` 拿到有效结果后激活，与「是否检出重复题」解耦（0 重复也允许导出）。

## 三、路径与参数交互优化

### 3.1 保存路径 hover + 打开文件夹
- 题库转 PPT 输出路径：`out_path_label` 保留 hover 看完整路径（`setToolTip`），新增「打开文件夹」次级按钮（无 Word 时置灰），与「更改」并列右对齐。

### 3.2 相似度阈值 ± 步进微调
- 阈值框两侧新增「−」「+」按钮（`QDoubleSpinBox.stepDown/stepUp`，步长 0.01），点击即微调并自动持久化（`_save_settings`）。
- 按钮复用 `secondary_bg` / `border` / `accent` 令牌，hover 高亮。

### 3.3 输入框聚焦 / hover 边框变色
- 题库转 PPT 与查重的 `QLineEdit` / `QSpinBox` / `QDoubleSpinBox` / `QComboBox` 统一：`border: 1px solid transparent` 默认 → `:hover` 主色边框 → `:focus` 主色边框 + `card_bg` 底色。透明边框避免聚焦时布局抖动。

## 四、容错与提示体验优化

### 4.1 轻量 Toast 场景
- 格式错误（拖入非法后缀）、解析失败、权限不足等统一经 `ToastNotification` 顶部滑入提示（✅/❌ + 自动消失），不再依赖仅日志输出。
- 转换 / 查重失败：`_on_pptx_failed` / `_on_failed` 经 Toast 提示错误信息。

### 4.2 成功后「打开目录」可点击链接
- 题库转 PPT：生成成功后 `progress_label` 渲染「打开文件夹」富文本链接（`linkActivated` 打开目录）。
- 试题查重：导出报告后新增 `_export_status` 富文本链接「✅ 报告已导出：xxx　打开文件夹」，点击直接打开所在目录。
