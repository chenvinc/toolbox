# 全局 UI 规范整改报告（阶段 1 · 含深/浅双模式完整规范）

> 范围：Quiz2Slide（题库转 PPT）、Similarity Checker（试题查重）两大模块全页面
> 目标：统一视觉规范、解决样式不统一、搭建标准化 UI 基础（不改动任何功能逻辑、不删减功能）
> 日期：2026-07-15
> 双模式要求：浅色按规范固化唯一色值，深色精确对齐补充双模式规范，全页面严格复用同一套设计令牌、视觉层级完全对等、支持系统配色自动切换

---

## 一、整改结论

全局视觉规范已**完全统一并落地深/浅双模式**：所有页面（主窗口导航、Quiz2Slide、Similarity Checker）严格复用同一套设计令牌，**浅色按规范固化、深色精确对齐补充规范**，深浅色一一对应、视觉层级完全对等，支持系统配色自动切换（`colorSchemeChanged`），无游离硬编码色值、无样式混乱。

统一后的核心标准如下，详细改动见第三节。

### 2. 圆角 / 间距 / 布局（双模式完全一致）

| 项目 | 标准 |
|------|------|
| 圆角 | **6px**（按钮、输入框、上传框、功能卡片、进度条、Toast 统一） |
| 页面内边距 | 上下 **20px**、左右 **24px** |
| 功能模块间距 | **16px** |
| 控件间距 | **8px** |

### 3. 字体层级（全系微软雅黑，含跨平台回退；双模式完全一致）

全局基础字体设为 `Microsoft YaHei`，回退链：`PingFang SC` / `Microsoft YaHei UI` / `SimHei` / `Heiti SC` / `sans-serif`（保证 macOS 等无该字体时优雅降级）。

| 层级 | 字号 / 字重 | 应用位置 |
|------|------|------|
| 页面大标题 | 14px 加粗 | 侧边栏标题、页面标题 |
| 模块小标题 | 13px 加粗 | 区块标题（选择来源 / 幻灯片风格 / 主文档…）、查重模式标签 |
| 常规标签 / 正文 | 12px 常规 | 字段标签、底部说明、结果文字 |
| 输入框提示 / 底部说明 | 12px 浅灰 | placeholder、说明文字 |
| 输入框录入文字 | 13px | 录入可读性，属规范内 13 级 |

### 4. 按钮基础规范（双模式完全一致）

| 类型 | 样式 | 尺寸 / 交互 |
|------|------|------|
| 主按钮 Primary | 蓝底 + 白字 + 无边框 | 高 40px；hover `#4096ff`、pressed `#0958d9`（深色主色 `#3b93ff`） |
| 次级按钮 Secondary | 白底 + 1px 蓝边框 + 蓝字 | 高 32px；hover 浅蓝（`#e6f4ff` / `#383852`） |
| 禁用按钮 Disabled | 灰底 + 浅灰字 | 无点击效果、无 hover（浅 `#d9d9d9` / 深 `#555566`） |

应用映射：开始转换 / 开始检测 = 主按钮；更改 / 重置 / 导出报告 = 次级按钮。

### 5. 双模式全局核心统一规则

1. **单一令牌来源**：所有颜色来自 `Theme` 的 `_set_colors`，所有几何 / 排版来自 `_set_tokens`（radius=6 / spacing=16 / control_spacing=8 / page_pad=24·20 / 字号 14·13·12·12），QSS 片段与控件样式统一从此取值。
2. **深浅一一对应**：同一色彩角色在浅 / 深各有精确映射值，切换前后视觉层级完全对等，无“浅色规范、深色协调”的不一致。
3. **系统自动适配**：`refresh()` 读取 `QApplication.styleHints().colorScheme()`，跟随系统深 / 浅切换；切换即时重建全部取色。
4. **QSS 热加载**：`theme.qss` 模板用 `$var` 占位符，`Theme` 每次读取并 `string.Template` 替换主题色，修改 qss 后下次主题刷新即生效；文件缺失回退内置 `_EMBEDDED_QSS`（同样使用令牌，与规范一致）。
5. **无游离硬编码**：所有页面仅通过 `Theme` 令牌取色，无硬编码十六进制色值。
