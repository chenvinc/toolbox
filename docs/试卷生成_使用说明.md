# 试卷生成（JSON → Word）使用说明

> 模块位置：工具箱「📝 试卷生成」页签。
> 功能：将粉笔题库导出的 JSON 题目数据，转换为 **题本** 与 **解析** 两份 Word 文档。

## 一、操作步骤

1. **导入题目数据**
   - 点击或拖拽 `.json` 文件到上传区（仅接受 `*.json`）。
   - 文件须为对象结构，含 `pageTitle`（试卷标题）与 `questions`（题目数组）。

2. **排版设置**（题本与解析同时生效）
   - **字体**：默认「宋体 / Times New Roman」，中文用宋体、英文/数字用 Times New Roman。
   - **字号**：如 五号 / 小四 等 Word 字号名。
   - **行间距**：1 倍 / 1.5 倍 / 2 倍 / 自定义（选「自定义」时出现数值框，范围 0.5–5.0）。
   - **首行缩进**：默认开启，正文段落首行缩进 2 字符；关闭则顶格。

3. **输出设置**
   - 默认输出到「与输入 JSON 同目录」。
   - 点击「选择目录」可指定其它输出位置；「打开文件夹」在生成后快速定位。

4. **生成**
   - 点击「开始生成」，按钮进入加载态，进度栏实时显示当前步骤：
     `解析中...` → `下载图片 x/n` → `生成题本...` → `生成解析...` → 完成。

## 二、输出文件

- 命名规则：`{pageTitle}_题本.docx` 与 `{pageTitle}_解析.docx`。
- 若 `pageTitle` 为空或含非法文件名字符，回退使用输入 JSON 文件名（去除后缀）。
- **题本**：题号 + 题干（含图）+ 选项，**不含答案**。
- **解析**：`【答案】` + `【正确率】` + `【解析】`，题干/解析中的图片按原比例内联。

## 三、图片下载

- 解析完成后，**并发预下载**全部题目图片（线程池上限 6，避免对图床造成压力被封）。
- 下载成功：按原始宽高比内联插入（不超过文本区可用宽度）。
- 下载失败：**不中断生成**，该处插入灰色占位框 `[图片加载失败: <URL>]`；
  生成完成后弹出报告，列出全部失败图片 URL，并在进度栏给出警告。

## 四、错误处理

| 场景 | 表现 |
| --- | --- |
| JSON 格式错误 / 题目为空 | 弹窗提示具体失败位置（如 `JSON 解析失败：…line 3 column 5`），不暴露堆栈 |
| 输出目录无写入权限 | 弹窗提示，并提供「选择目录」按钮，选好目录后自动重试生成 |
| 部分图片下载失败 | 进度栏警告 + 完成后弹窗列出失败图片列表，生成照常完成 |
| 其他异常 | 顶部 Toast 友好提示，不暴露堆栈 |

## 五、注意事项

- 图片为远程地址时需联网；离线时相关图片以占位框替代，不影响文档结构。
- 排版参数（字体/字号/行距/首行缩进）会被记住，下次打开自动恢复。
- 页边距与参考模板一致（左右 1.25″、上下 1″），正文首行缩进 2 字符。
